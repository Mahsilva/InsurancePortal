Project name:

Greenstone Insurance Portal

Developed a full-stack car insurance web portal as part of 
my Capstone Project at university. The system allows customers 
to purchase insurance policies, submit claims with photo evidence, 
and make payments online. Administrators can manage customers, 
policies, claims and payments through a dedicated admin panel.


✅ What I built:
- Customer portal — buy policies, submit claims, make payments
- Admin dashboard — manage customers, approve/reject claims
- Secure login system with role-based access control
- Photo upload for insurance claims
- Cloud deployment with Docker + Railway + Netlify

💻 Tech Stack:
C# | ASP.NET Core | Entity Framework Core | PostgreSQL | 
HTML/CSS/JS | Docker | GitHub | Railway | Netlify
